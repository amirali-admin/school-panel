# سامانه هوشمند مدرسه

## اجرا
```bash
npm install
npm start
```
سپس `http://localhost:3000` را باز کنید.

## حساب‌های اولیه
- مدیر: `admin` — رمز پیش‌فرض: `Admin@12345`
- دانش‌آموز: `student1` — رمز پیش‌فرض: `Student@12345`

در محیط واقعی حتماً رمزها را با متغیرهای محیطی تغییر دهید.

## امکانات
- صفحه عمومی با تابلو تبلیغات، امکانات و اطلاعیه‌ها
- ورود امن با نقش‌های مدیر و دانش‌آموز
- مدیریت کاربران
- ثبت و حذف نمرات
- مدیریت اطلاعیه‌ها
- مدیریت تابلو
- پنل اختصاصی دانش‌آموز برای مشاهده نمرات و میانگین
- طراحی RTL، واکنش‌گرا و آبی/سفید
